# 📖 Project Overview

The **Student Management System** is a professional full-stack web application developed to simplify student administration. It provides administrators with a secure and user-friendly platform to manage students, courses, attendance, and academic records efficiently.

The application follows a modern client-server architecture using **React.js** for the frontend, **Node.js & Express.js** for the backend, and **MongoDB** for database management. REST APIs are used to enable seamless communication between the frontend and backend.
